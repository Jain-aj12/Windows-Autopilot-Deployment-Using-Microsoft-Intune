# Windows Autopilot Deployment Using Microsoft Intune

## 1. Project Overview

This project demonstrates the end-to-end Windows Autopilot deployment process using Microsoft Intune and Microsoft Entra ID.

## 2. Project Objective

To understand how organizations automatically provision Windows 11 laptops for employees without manually configuring every device.

## 3. Technologies Used

- Microsoft Intune
- Microsoft Entra ID
- Windows Autopilot
- Windows 11
- PowerShell
- Microsoft Endpoint Management

## 4. Deployment Workflow

1. Prepare Microsoft Intune tenant.
2. Configure automatic MDM enrollment.
3. Collect Windows hardware hash.
4. Register devices with Windows Autopilot.
5. Create Microsoft Entra security group.
6. Configure Enrollment Status Page.
7. Create Windows Autopilot deployment profile.
8. Assign the profile to the device group.
9. Deploy Windows 11 device.
10. Verify device enrollment and compliance.

## 5. Project Structure

- Prerequisites

## 6. Expected Outcome

A Windows 11 device is provisioned using Windows Autopilot, joined to Microsoft Entra ID and enrolled into Microsoft Intune.
